# Spese mensili

PWA italiana senza dipendenze, con dati in localStorage e backup JSON.

## Pubblicazione
GitHub Settings → Pages → Deploy from a branch → main → / (root).

## Installazione
Aprire il sito in Safari su iPhone → Condividi → Aggiungi alla schermata Home. Dopo la prima apertura online, il service worker conserva i file per l'utilizzo offline.

I dati inseriti restano sul dispositivo. I valori iniziali del budget sono presenti nel codice. Il backup della precedente versione è compatibile.
